# Kiro usage log

One row per real use of a Kiro feature. Add a row when it happens, not afterwards from memory. The "How Kiro was used" write-up in `docs/Submission_Drafts.md` is written only from this log. Do not add rows for features that were not used.

Columns:

- Date: UTC date of the session (YYYY-MM-DD).
- Kiro feature: spec, design, tasks, steering, hook, property-based test, MCP, vibe/chat, other.
- What was asked: the prompt or the task, in one or two sentences.
- Outcome: what Kiro produced and whether it was kept, edited or discarded.
- What it caught or changed: defects found, requirements changed, code changed by the feature.
- Commit: hash of the commit holding the result.
