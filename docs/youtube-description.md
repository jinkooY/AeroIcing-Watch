# Title

Cloud Dive: fly a real cloud day, spend the least fuel (Kiroween 2026)

# Description

Cloud Dive is a browser fuel game on real data: a regional jet flies New York (KJFK) to Nashville (KBNA) on
12 November 2026 through cloud measured by the GOES-19 satellite and an ECMWF forecast. At each gate you choose
lane, altitude and anti-ice; the lowest fuel cost wins. Every label says how much the data really knows.

Play free (no login): https://jinkooy.github.io/AeroIcing-Watch/
Code (Apache-2.0): https://github.com/jinkooY/AeroIcing-Watch

Built with Kiro for the Kiroween 2026 hackathon: spec-driven development, steering, hooks, a custom agent in
Kiro IDE and Kiro CLI, an MCP browser server and a Kiro power.

Limits: game model, not a flight procedure, not an icing severity. Costs are illustrative. The ice index is a
game state, not an icing model. Accuracy has not been evaluated.

Narration: AI voice (Google Gemini text-to-speech). Cloud shots are illustrations rendered from the satellite
cloud-top data. Data: NOAA GOES-R (public domain), ECMWF Open Data (CC BY 4.0).
