# Cloud Dive - 3분 제출 영상 가이드와 시나리오 (C15)

> 3~4장은 `docs/video/storyboard.md`와 `docs/video/script.json`으로 대체됨.

기준: `requirements.md` R12.1, `submission-checklist.md` C15, 결정 G11.
영상은 기능 동결(2026-11-28) 이후 완성된 빌드로 녹화한다. 케이스는 KJFK-KBNA (2026-11-12), 3D 조종석 화면을 쓴다.

## 1. 시나리오 평가

제안한 틀("게임은 재미를 위한 포장이고, 안에는 실제 데이터와 저비용 증거 엔진이 있다")은 심사 기준과 잘 맞는다.

- Potential Impact: 같은 엔진이 디스패처용 단면도와 API로도 쓰인다는 점이 영향력 근거가 된다.
- Technological Implementation: GOES 구름 관측과 ECMWF 예보를 정적 케이스 파일로 미리 계산한다. 서버가 없고 호스팅 비용이 0이다. 판정에는 LLM이 없고 결정론적이다.
- Innovation: 과학 데이터를 게임 점수(연료비 달러)로 바꾼 점.
- Design / Presentation: 조종석 화면에서 구름 앞에서 멈추고 선택하는 흐름.

주의할 점이 둘 있다.

1. "과학적으로 근거 있다"는 "실제 관측과 예보를 쓰고, 증거 등급을 정직하게 표시한다"로 말한다. "결빙을 예측한다", "검증됐다"는 말은 쓰지 않는다. 얼음 지수는 게임 상태값이고 항공기 결빙 모델이 아니다. 비용 숫자(연료 단가, 항빙 계수 등)는 "illustrative"로 말한다.
2. "저비용"은 측정 가능한 사실로만 말한다. 예: 정적 사이트, 서버 없음, 무료 공개 데이터, 호스팅 0달러. 실제 항공사 절감액은 주장하지 않는다.

## 2. 제출 규칙 체크 (영상)

- 3:00 미만 (목표 2:50 전후), YouTube 공개, 영어 AI 음성, 자막 포함.
- 앱이 실제로 동작하는 화면을 보여 준다.
- 제3자 로고와 음악 금지. CIRA, NOAA 화면 캡처 금지. 데이터 출처는 앱 안의 텍스트 표기만 보여 준다.
- 공개 사용이 허용되는 음성 서비스 약관을 확인한다.
- 게임 안내 문구(game note)가 화면에 보이게 둔다. "지면은 평평하다", "프레임 속도는 노트북 한 대에서만 측정했다"를 말한다.
- KDEN-KLAX는 영상에서 쓰지 않는다.

`docs/video/storyboard.md`(화면, 타임라인, 게이트 계획)와 `docs/video/script.json`(영어 대본), `docs/video/script-ko.md`(한글 검토본)로 대체되었습니다. 이 가이드의 3장과 4장은 지웠습니다.

## 5. 녹화 가이드

1. 준비: 1920x1080, 브라우저 전체화면, 알림 끄기, 북마크 바 숨김. 다른 탭에서 로고가 보이지 않게 한다.
2. 화면 녹화는 OBS 같은 도구로 60fps 또는 30fps. 영상은 장면별로 따로 녹화하고 편집에서 잇는다.
3. 플레이 장면은 미리 두세 번 연습한다. 데모 계획의 게이트(0 km 예보만, 500 km 관측 등 16개)는 `node tools/video/gate_plan.mjs`로 계산했다. 같은 케이스는 결정론적이라 같은 결과가 재현된다.
4. 이륙과 상승은 Space 또는 Skip 버튼으로 건너뛴다. 영상에는 2~3초만 보인다.
5. 내레이션은 영어 텍스트를 AI 음성 서비스에 넣어 파일로 만든다. 약관에서 공개 게시 허용을 확인한다. 문장 사이를 0.3초 띄우고, 화면 동작에 맞춰 편집한다.
6. 자막: 내레이션 텍스트를 SRT로 만들어 YouTube에 올린다. 영상에 자막을 직접 입히면 더 안전하다.
7. 음악은 넣지 않는다. 효과음도 직접 만든 것만 쓴다.
8. 최종 길이 2:50 전후로 맞춘다. 3:00에 가까우면 2:15-2:40 구간을 줄인다.

## 6. 업로드 전 점검

- [ ] 3:00 미만, 영어, 자막 있음
- [ ] 로고와 음악 없음, CIRA/NOAA 화면 없음
- [ ] 앱 화면과 출처 표기(원본 시각 UTC 포함)가 보임
- [ ] 금지 표현 없음: "predicts icing", "certified", "validated", "safe to fly"
- [ ] 비용과 얼음 지수는 illustrative 또는 game state라고 말함
- [ ] 장면 수치(X달러)가 실제 빌드와 일치
- [ ] g5("Anti-ice off, flying on?")가 리포트의 Straight-ahead 기준과 다른 것으로 들리고 보인다
- [ ] storyboard의 숫자를 녹화 당일 케이스 파일로 다시 계산했다 (`node tools/video/gate_plan.mjs`)
- [ ] YouTube 공개 설정, Devpost 양식에 링크 입력 (C17)
