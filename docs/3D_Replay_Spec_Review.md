# 3D 항로 재생 작업명세서 검토

검토일 2026-11-12 · 대상 `AeroIcing_Watch_3D_항로재생_작업명세서.md` (초안, 기준 `32c93f5`)

명세서의 범위와 단계 구분은 타당하다. 2단계(위성)와 3단계(지도 편집)는 시작 조건이 아직 충족되지 않았으므로 이번 작업은 1단계(R1–R5)만 다룬다. 디자인은 기능 동작 수준으로만 구현하고 별도로 재검토한다.

## 코드 대조 결과

| 항목 | 확인 내용 | 영향 |
|---|---|---|
| 구간 경계 좌표 | `legs_for`가 경유점 쌍마다 25 km 이하 등분 구간을 만들고 중점만 저장한다. 경계는 같은 측지 계산으로 정확히 복원할 수 있다. | IFS 재실행 없이 R2 가능. 평가기와 내보내기가 같은 분할 함수를 써야 한다. |
| 중점 ETA | 저장된 ETA는 수렴 직전 반복의 `now + duration/2`로, 경계 기반 중점과 0.1초 미만 차이. | 명세의 “중점 시각” 해석이 맞다. 허용 오차를 명시해야 한다. |
| 2D 지도 | `routeGeometry`가 경유점을 가장 가까운 중점 사이에 끼워 넣는 추정으로 선을 그린다. | 경계 궤적을 내보내면 2D·3D가 같은 선을 쓸 수 있다. |
| 스키마 | 2D 화면이 `schema_version !== 1`이면 로딩을 거부한다. | 버전을 올리면 2D 확인 로직도 함께 바꿔야 한다. |
| 배포 | Pages 워크플로가 `static/route-demo` 전체를 올린다. | 3D 파일을 같은 폴더에 두면 R5 배포 범위는 자동 충족. |
| 테스트 | 저장소에 테스트가 없었다. | 데이터 계약 테스트를 추가했다. |

## 개선 제안

1. **경계 분할 공유(R2)**: 분할 로직을 `route_sampler.split_legs`로 옮기고 평가기와 내보내기가 함께 쓴다. 내보내기는 복원한 중점이 보관 응답과 1e-7° 이내인지, 중점 ETA가 1초 이내인지, 경계 시각 합이 `total_time_s`와 같은지 검사하고 어긋나면 실패한다. → 반영 완료.
2. **데이터 계약 명시(R1)**: `schema_version` 2, 최상위 `replay` 메타(높이 기준, 시간 기준, 보간 방식)와 경로별 `replay.track`(경계 위경도·UTC·누적거리·경유점), `status`·`stopped_segment_index`·`stopped_reason`을 추가한다. 구간에 `id`(`direct-001`)와 `index`를 둔다. → 반영 완료.
3. **결측 처리 구체화(R4)**: 시간이 계산되지 않은 경계는 `time: null`로 두고, 재생은 마지막 시각이 있는 경계에서 멈추며 `stopped_reason`을 보여준다.
4. **2D·3D 연동 방식**: URL 해시 `#route=<id>&segment=<index>`로 양방향 이동한다. 명세의 “기존 비교 화면 연동”을 정적 배포에서 구현하는 가장 단순한 방법이다.
5. **배경지도와 키(R5)**: Cesium ion 기본 영상은 토큰이 필요하다. Cesium에 포함된 NaturalEarthII 타일을 쓰고 ion, 지오코더, 지형을 끈다. CesiumJS는 Apache-2.0이며 버전을 고정해 CDN에서 불러온다.
6. **항공기 표현(R3)**: glTF 모델 대신 직접 그린 SVG 아이콘을 진행 방향으로 회전한다. 라이선스 확인이 필요 없고 모바일 부담이 작다.
7. **높이 표기**: FL300 → 9,144 m는 ISA 환산 표시값이며 타원체 높이로 그린다. 과장 배율을 쓰면 배율을 화면에 적는다.
8. **WebGL 대체**: Viewer 생성 실패나 WebGL 미지원 시 같은 해시를 유지한 채 2D 화면 링크를 보여준다.
9. **명세 보완 필요 항목**: 재생 배율 기본값(예: 60×), 두 후보 재생 시간이 다를 때의 표시, 모바일 최소 지원 범위를 명세에 적는다.
